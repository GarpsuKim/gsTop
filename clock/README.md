# 영원한 시계 (Clock)

폰을 탁상시계·인테리어 시계로 쓰기 위한 안드로이드 앱입니다.
아날로그·디지털 시계 위에 사진 슬라이드쇼, 동영상, 유튜브 영상을 배경으로 깔고, 음악까지 함께 틀 수 있습니다.
매시 시보, 홈 화면 위젯, 화면 분할(시계 + 앱 목록)도 있습니다.
앱이 떠 있는 동안에는 화면이 꺼지지 않습니다.

- 언어: Kotlin + Jetpack Compose (Material 3), 도움말 표시에 commonmark-java
- 최소 Android 8.0 (API 26), 대상 API 34
- 앱 ID: `io.github.garpsukim.clock` (텔레그램 빌드는 `io.github.garpsukim.clock.kja`). 코드 위치(namespace)는 `com.example.clock`

---

## 화면 다루기

- 앱은 버튼 없이 전체화면으로 시작합니다. **화면을 한 번 누를 때마다** 버튼이 보이기/숨기기 됩니다.
- 처음 실행할 때 사용자 성명이 없으면 **사용자 등록** 창이 뜹니다.
- 첫 실행 때 홈 화면 바로가기 추가를 요청합니다 (adb 로 설치하면 아이콘이 자동으로 생기지 않으므로).
- **[뒤로] 키로는 앱이 닫히지 않습니다.** 열린 메뉴·창·폴더만 닫습니다.
  앱이 닫히는 경우는 한 손가락 스와이프(아래)와 [닫힘] 시간이 다 됐을 때뿐입니다.
- OLED 번인 방지: 3분마다 화면 전체를 4dp 씩 옮깁니다 (가운데 → 8방향, 27분에 한 바퀴).

### 한 손가락 스와이프 (모든 모드)

100dp 이상 밀어야 동작합니다. 버튼·슬라이더·메뉴가 먼저 받은 끌기는 무시합니다.

| 상태 | ← | → | ↑ | ↓ |
|---|---|---|---|---|
| 가로, 분할 안 됨 | 左 분할 (왼쪽 시계) | 右 분할 (오른쪽 시계) | 앱 종료 | 앱 종료 |
| 세로, 분할 안 됨 | 앱 종료 | 앱 종료 | 上 분할 (위 시계) | 下 분할 (아래 시계) |
| 左 시계 / 右 앱 목록 | 앱 종료 | 분할 해제 | – | – |
| 左 앱 목록 / 右 시계 | 분할 해제 | 앱 종료 | – | – |
| 上 시계 / 下 앱 목록 | – | – | 앱 종료 | 분할 해제 |
| 上 앱 목록 / 下 시계 | – | – | 분할 해제 | 앱 종료 |

- 분할 중에는 **시계 쪽으로 밀면 앱 종료, 앱 목록 쪽으로 밀면 분할 해제**입니다. 직각 방향(–)은 아무 일 없음.
- 시스템 화면 분할(다른 앱과 나란히) 중에는 "앱 종료" 방향만 동작합니다.

## 버튼과 메뉴

버튼은 두 묶음입니다: **왼쪽 위** (모드·글자·날짜·초침·화면), **오른쪽 아래** (디자인/스크롤·배경·달력·시보·알람).
`▾` 가 붙은 버튼은 메뉴가 열립니다. 영역이 여러 개인 메뉴는 2단계입니다:
영역 목록(오른쪽에 지금 값) → 영역을 누르면 그 영역의 항목만.

| 날짜 ▾ (왼쪽 위) | **위치**: 날짜 끔 / 날짜(상) / 날짜(하) — 월·일·요일 줄<br>**날짜색**: 흰색 ~ 무지개 (날짜를 켰을 때만) |
| 스크롤 ▾ (오른쪽 아래) | 끔 / ← / → / ↔ / ↑ / ↓. 화면을 **꾹 누르면** 스크롤 끔 |

### 🖼 배경 ▾ (오른쪽 아래, 모든 모드)
배경 우선순위: **유튜브 > 동영상 > 이미지 > 검정**

| 영역 | 항목 |
|---|---|
| 이미지 | 지금 사진 이름 / 사진 선택 (1장 = 고정, 여러 장 = 3초 간격 슬라이드쇼) / 무한 반복 / 검은색 / 끄기 |
| 동영상 | 지금 파일 / **재생 위치 슬라이더** / 동영상 선택 (여러 개 연속 재생) / 무한 반복 / 소리 / 끄기 |
| 음악 | 현재 곡 / **재생 위치 슬라이더** / 재생·일시정지 / 다음 곡 / 다른 음악 선택 / 끄기 |
| 유튜브 | 유튜브 주소 입력… (영상·재생목록, 소리 선택) / 끄기 |

- 사진은 앱 내부에 축소 복사(긴 변 2560px)해 두므로 원본을 지워도 배경이 유지됩니다.
- 동영상은 복사하지 않고 원본 읽기 권한만 저장합니다.
- 유튜브 앱에서 영상을 **공유 → 시계** 하면 주소가 자동으로 들어옵니다. 파일 앱에서 음악을 **공유 → 시계** 하면 바로 재생합니다.
- 음악: 여러 곡이면 차례로 재생 후 처음부터 반복 (한 곡이면 그 곡 반복). 앱을 나가면 일시정지, 돌아오면 이어서 (화면 회전에는 끊기지 않음).
- **검은 배경 투명도**: 배경이 검정일 때 슬라이더로 투명도를 조절하면 폰 배경화면이 비쳐 보입니다.
  가로 화면은 오른쪽에 세로 슬라이더(위로 = 투명), 세로 화면은 시계와 아래 버튼 줄 사이에 가로 슬라이더(오른쪽 = 투명).

### 📅 달력... (오른쪽 아래)
목록에서 골라 기본 브라우저로 엽니다: 달력(음력), 날씨(기상청), 일출일몰(천문연구원), 세계시.

### 🔔 시보·알람 ▾ (오른쪽 아래)
| 영역 | 기능 |
|---|---|
| 시보 | 시보 설정 창 (아래 [시보](#시보-매시-연주)). 버튼 아이콘으로 켜짐/꺼짐 표시 |
| 알람 | 시스템 시계 앱의 알람 화면 열기 |
| 닫힘 | 닫힘 설정 창: 켜면 화면을 만지지 않은 채 정한 시간(30초 ~ 5일)이 지나면 시계를 닫음 → 폰이 평소대로 화면을 끔. "지금부터 만지지 않으면 ○시 ○분에 닫힙니다" 안내. 끄면 무한 |

## 시보 (매시 연주)

앱이 꺼져 있어도 정확한 알람으로 깨어나 연주합니다 (포그라운드 서비스, 알림에 [정지] 버튼).

- **소리**: 괘종시계 종소리(앱이 직접 합성, 시각 수만큼 침: 1~12번) 또는 고른 음악 파일
- **울리는 시각**: 매시 정각 또는 매시 ○분
- **연주 시간**: 5초 ~ 30분, 또는 끝까지 (다음 시보와 겹치지 않게 최대 59분). 곡은 반복하지 않음
- **건너뛸 시각**: 0~23시 중 체크한 시각은 울리지 않음 (기본: 1~5시)
- **진동·무음 모드에서도 울리기**: 켜면 미디어 음량으로 울림 (끄면 소리 모드일 때만)
- 통화 중에는 울리지 않고, 다른 소리는 시보 동안 잠시 작아짐
- [들어보기] 로 바로 한 번 연주
- 재부팅·시각/시간대 변경·앱 업데이트 뒤에도 알람을 다시 맞춤

## 화면 분할

[⧉ 화면] 메뉴 또는 한 손가락 스와이프로 화면을 둘로 나눕니다. 한쪽은 시계(배경 포함), 다른 쪽은 **앱 목록**.

- 가운데 구분선을 끌어 비율 조절 (25% ~ 75%), 두 번 누르면 반반.
- 분할 자리는 저장되어 앱을 다시 열어도 분할된 채로 시작합니다. 화면을 돌리면 左↔上, 右↔下 로 맞춥니다.
- 앱 목록에서 앱을 누르면 "옆에 열기"로 실행 → 삼성 폰에서는 시스템 화면 분할로 시계와 나란히 열립니다.

### 앱 목록
- **검색창**: 이름 일부 또는 초성 ("ㅋㅋㅇ" → 카카오톡, 글자와 초성 섞어도 됨)
- **고정**: 앱을 길게 누르면 위에 고정/해제 (핀 표시)
- **홈 화면 폴더**: 삼성 홈 화면의 폴더(그룹)를 홈 화면 순서대로 (작은 아이콘 2×2 + 폴더 이름).
  누르면 그 폴더의 앱만 보이고, 맨 위 [← 폴더 이름] 이나 [뒤로] 로 닫으면 보던 위치로 돌아옵니다. 검색 중에는 숨김.
  삼성 홈(One UI Home)이 다른 앱에 열어 둔 배치 정보(`get_home_item_info` / `get_home_only_item_info`)를 읽으며,
  삼성 폰이 아니거나 읽기에 실패하면 폴더 없이 앱 목록만 보입니다 (logcat 태그 `ClockFolders`).
- **모든 앱**: 이름순

## 사용자 등록 · 홈 화면 위젯

- **사용자 등록** ([🕐 모드] → 사용자 등록): 사용자 성명 + 긴급 연락처 (연락처 앱에서 하나 선택 → 연락처 권한 불필요).
  긴급 연락처를 고르면 전화 권한을 요청합니다.
- **홈 화면 위젯** (납작한 2줄, 기본 4×1):
  1줄 오전/오후 HH:MM(:SS), 2줄 MM월 DD일 X요일 + 사용자 성명.
  - **한 번 누르기** = 시계 앱을 전체화면으로 열기
  - **두 번 누르기** = 긴급 연락처로 전화 (전화 권한이 없으면 번호가 입력된 전화 앱)
  - 위젯을 추가할 때와 길게 눌러 "위젯 설정"(Android 12+) 할 때: 시각 / 날짜 / 성명 글자색, 초 표시 (위젯마다 따로)

## 빌드 · 설치

Android Studio 없이 명령줄로 빌드합니다. (Android SDK: `C:\Android\sdk`, compileSdk 34)

| 파일 | 용도 |
|---|---|
| `_BUILD_WIFI.BAT` | 와이파이 설치용 디버그 APK 빌드 (앱 이름 = 이 파일의 `set "AppIcon=..."`) → `app\build\outputs\apk\debug\app-debug.apk` |
| `_BUILD_Telegram.BAT` | 텔레그램 전송용 디버그 APK 빌드 (앱 이름 = 이 파일의 `set "AppIcon=..."`) |
| `_RUN_TELEGRAM.BAT` | `_BUILD_Telegram.BAT` 로 빌드 → 텔레그램 봇으로 폰에 전송 (`telegram_config.bat`에 `BOT_TOKEN`, `CHAT_ID` 필요) |
| `_RUN_WIFI.BAT` | `_BUILD_WIFI.BAT` 로 빌드 → adb 무선 디버깅으로 폰에 설치·실행 (IP/포트 입력, 마지막 주소는 `adb_addr.txt`에 기억) |
| `_DUMP_PREFS.BAT` | 폰에서 지금 쓰는 설정 파일(`clock_prefs.xml`, `chime_prefs.xml`)을 꺼내 `prefs_dump` 폴더에 저장 (와이파이 adb, 디버그 빌드) |
| `_DUMP_CHIME.BAT` | 시보 진단: 시보 설정, 맞춰진 알람, 정확한 알람 권한, 벨소리 모드, 배터리 제한, 최근 시보 로그를 `prefs_dump\chime_diag.txt` 로 |
| `_github_push.bat` | 커밋 후 [gsTop/clock](https://github.com/GarpsuKim/gsTop/tree/main/clock) 에 올리기 |

앱 이름과 앱 ID 는 빌드 bat 이 `-PappNameBat=<자기 파일 이름>` 을 넘기면 `app/build.gradle.kts` 가 그 파일의 `AppIcon`(이름), `AppIdSuffix`(앱 ID 꼬리) 줄을 UTF-8 로 직접 읽어 정합니다 (한글이 깨지지 않게). `gradlew` 를 직접 실행하면 `_BUILD_WIFI.BAT` 의 값을 씁니다.

| 빌드 | 앱 이름 | 앱 ID |
|---|---|---|
| `_BUILD_WIFI.BAT` | 영원한_시계 | `io.github.garpsukim.clock` |
| `_BUILD_Telegram.BAT` | KJA시계 | `io.github.garpsukim.clock.kja` |

앱 ID 가 달라서 한 폰에 두 앱을 따로 설치할 수 있습니다 (설정·시보·위젯도 각자 따로).

빌드할 때 자동으로 정해지는 것 (`app/build.gradle.kts`):
- **버전**: 버전 이름 = 빌드 날짜 (`2026.11.26`), 버전 번호 = `yyMMdd` (`261126`), git 커밋 번호 (`a99d6bf`, 커밋 안 한 변경이 있으면 끝에 `+`) → [정보] 창에 표시
- **도움말**: 맨 위의 `README.md` 를 앱 안(assets)으로 복사 → README 를 고치면 다음 빌드에 반영. 도움말에는 `## 소스 구성` 앞까지만 보임

`local.properties`, `telegram_config.bat`, `adb_addr.txt`, `prefs_dump`, 빌드 결과물은 `.gitignore`로 제외되어 GitHub에 올라가지 않습니다.

## 권한

| 권한 | 용도 |
|---|---|
| `INTERNET` | 유튜브 배경 재생 |
| `SET_ALARM` | 시스템 시계 앱의 알람 화면 열기 |
| `CALL_PHONE` | 위젯 두 번 누르기 → 긴급 연락처로 바로 전화 (거부하면 전화 앱에 번호만) |
| `USE_EXACT_ALARM` (Android 12 이하 `SCHEDULE_EXACT_ALARM`) | 시보: 매시 정확한 시각에 깨어나기 |
| `RECEIVE_BOOT_COMPLETED` | 시보: 재부팅 후 알람 다시 맞추기 |
| `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_MEDIA_PLAYBACK`, `WAKE_LOCK` | 시보: 앱이 꺼져 있어도 연주 |
| `POST_NOTIFICATIONS` | 시보 연주 중 알림 ([정지] 버튼). 거부해도 시보는 울림 |
| `com.samsung.android.launcher.permission.READ_SETTINGS` | 화면 분할 앱 목록에 삼성 홈 화면 폴더 표시 (일반 권한, 동의 창 없음) |

사진·동영상·음악은 시스템 파일 선택기로, 긴급 연락처는 연락처 앱에서 고른 한 건만 읽으므로 저장소·연락처 권한이 필요 없습니다.
