# 영원한 시계 (Clock)

폰을 탁상시계·인테리어 시계로 쓰기 위한 안드로이드 앱입니다.
아날로그·디지털 시계 위에 사진 슬라이드쇼, 동영상, 유튜브 영상을 배경으로 깔고, 음악까지 함께 틀 수 있습니다.
앱이 떠 있는 동안에는 화면이 꺼지지 않습니다.

- 언어: Kotlin + Jetpack Compose (Material 3)
- 최소 Android 8.0 (API 26), 대상 API 34
- 패키지: `com.example.clock`

---

## 주요 기능

### 시계 표시
| 표시 방식 | 설명 |
|---|---|
| 아날로그 | 시침·분침·(선택) 초침과 날짜·요일 |
| 하이브리드 | 아날로그 + 디지털 시각 함께 |
| 디지털 | 화면 가득 큰 숫자 시계 |

- **테마 (아날로그/하이브리드)**: 기본, 무지개, 네온, 오션, 선셋, 포레스트, 벚꽃, 골드, 실버, 레드
- **애니메이션**: 별빛 반짝임, 초 단위 펄스, 혜성 궤도, 초침 잔상, 눈 내리는 밤, 숨쉬는 빛, 회전 햇살, 떠오르는 방울, 행성 공전, 물결 파동 (또는 OFF)
- **디지털 옵션**: 굵게, 네온사인, 글자색(흰색·빨강·주황·노랑·초록·하늘·파랑·보라·분홍·무지개), 스크롤(OFF / ← / → / ↔)
- **전원 모드**
  - 고급 모드: 1초에 20번 갱신 → 초침이 부드럽게 흐름
  - 전원 절약 모드: 1초에 1번 갱신 → 초침 "똑딱", CPU 사용량 크게 감소

### 배경
배경 우선순위: **유튜브 > 동영상 > 이미지 > 검정**

| 버튼 | 기능 |
|---|---|
| 🖼 배경(이미지) ▾ | 사진 선택 (1장 = 고정, 여러 장 = 3초 간격 슬라이드쇼), 무한 반복, 검은색, 끄기. 지금 보이는 사진 이름 표시 |
| 🎬 배경(동영상) ▾ | 동영상 여러 개 연속 재생, 무한 반복, 소리 켜기, 끄기. 지금 재생 중인 파일 이름과 **재생 위치 슬라이더** |
| ▶ 유튜브 | 유튜브 영상/재생목록 주소를 배경으로 반복 재생 (소리 선택), 끄기 |

- 사진은 앱 내부에 축소 복사(긴 변 2560px)해 두므로 원본을 지워도 배경이 유지됩니다.
- 동영상은 복사하지 않고 원본 읽기 권한만 저장합니다.
- 유튜브 앱에서 영상을 **공유 → 시계** 하면 주소가 자동으로 들어옵니다.
- **검은 배경 투명도**: 배경이 검정일 때 슬라이더로 투명도를 조절하면 폰 배경화면이 비쳐 보입니다.
  세로 화면은 오른쪽 가운데에 세로 슬라이더, 가로 화면은 상단 가운데에 가로 슬라이더로 나옵니다. (기본값 0%)

### 음악
- ♪ 음악 버튼으로 여러 곡 선택 → 차례로 재생, 끝나면 처음부터 반복 (한 곡이면 그 곡 반복)
- 메뉴: 현재 곡 이름, **재생 위치 슬라이더**, 재생/일시정지, 다음 곡, 다른 음악 선택, 끄기
- 파일 앱에서 음악을 **공유 → 시계** 하면 바로 재생
- 앱을 나가면 일시정지, 돌아오면 이어서 재생 (화면 회전에는 끊기지 않음)

### 기타 버튼
| 버튼 | 기능 |
|---|---|
| 📅 달력... | 목록에서 골라 기본 브라우저로 열기: 달력(음력), 날씨(기상청), 일출일몰(천문연구원), 세계시 |
| ⏰ 알람 | 시스템 시계 앱의 알람 화면 열기 |
| ↺ 초기화 | 확인 후 모든 설정을 처음 상태로 (배경 사진도 삭제) |

- 화면을 한 번 누를 때마다 버튼들이 보이기/숨기기 됩니다.
- 첫 실행 때 홈 화면 바로가기 추가를 요청합니다.

## 소스 구성

```
app/src/main/java/com/example/clock/
├── MainActivity.kt          화면 구성, 배경 레이어, 폰 배경화면 투명도, 공유 받기, 홈 바로가기
└── ui/
    ├── ClockScreen.kt       메인 화면, 설정(저장/불러오기), 버튼들, 아날로그 시계, 달력/알람
    ├── DigitalScreen.kt     큰 디지털 시계 (굵게·네온·스크롤·글자색)
    ├── AnimationLayer.kt    시계 판 애니메이션 효과
    ├── BackgroundImage.kt   배경 사진 저장소 + 슬라이드쇼
    ├── VideoBackground.kt   배경 동영상 재생기(ExoPlayer) + 메뉴
    ├── YouTubeBackground.kt 유튜브 배경(WebView + IFrame API) + 주소 입력 창
    ├── MusicPlayer.kt       음악 재생기(MediaPlayer) + 메뉴
    ├── PlaybackSlider.kt    재생 위치 슬라이더 (음악·동영상 공용)
    ├── TransparencySlider.kt 검은 배경 투명도 슬라이더 (세로/가로)
    ├── FileNames.kt         파일 표시 이름 읽기, 메뉴의 "지금 파일" 줄
    ├── InlineMenu.kt        화면 안에 그리는 드롭다운 메뉴 (갤럭시 팝업 터치 문제 회피)
    └── theme/Theme.kt
```

설정은 `SharedPreferences`(`clock_prefs`)에 저장됩니다.

## 빌드 · 설치

Android Studio 없이 명령줄로 빌드합니다. (Android SDK: `C:\Android\sdk`, compileSdk 34)

| 파일 | 용도 |
|---|---|
| `_BUILD.BAT` | 디버그 APK 빌드 → `app\build\outputs\apk\debug\app-debug.apk` |
| `_RUN_TELEGRAM.BAT` | 빌드한 APK를 텔레그램 봇으로 폰에 전송 (`telegram_config.bat`에 `BOT_TOKEN`, `CHAT_ID` 필요) |
| `_RUN_WIFI.BAT` | adb 무선 디버깅으로 폰에 설치·실행 (IP/포트 입력, 마지막 주소는 `adb_addr.txt`에 기억) |
| `_github_push.bat` | 커밋 후 [gsTop/clock](https://github.com/GarpsuKim/gsTop/tree/main/clock) 에 올리기 |

`local.properties`, `telegram_config.bat`, `adb_addr.txt`, 빌드 결과물은 `.gitignore`로 제외되어 GitHub에 올라가지 않습니다.

## 권한

| 권한 | 용도 |
|---|---|
| `INTERNET` | 유튜브 배경 재생 |
| `SET_ALARM` | 시스템 시계 앱의 알람 화면 열기 |

사진·동영상·음악은 시스템 파일 선택기로 고른 파일만 읽으므로 저장소 권한이 필요 없습니다.
