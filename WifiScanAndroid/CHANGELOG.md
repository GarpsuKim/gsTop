# 변경 기록

버전 규칙: `주.부.수` (큰 변화 → 주, 기능 추가 → 부, 오류·문구 수정 → 수).
새 APK를 낼 때마다 `app/build.gradle` 의 `versionCode` 를 1씩 올리고 `versionName` 을 바꾼 뒤 여기에 적습니다.

## 1.1.0 (versionCode 2) — 2026-11-22

### 바뀐 점
- 앱 이름 "와이파이 스캔" → **집에왔어요**, 앱 아이콘 등록
- 화면 맨 위: [초기화] / ☐ 백그라운드 실행 / [종료], 상태 옆 큰 **🆘 SOS** 버튼
- 탭 구성: (1) 홈 공유기 등록 · (2) 현재 위치 · (3) 알림 설정 · (4) 위치 보내기 · (5) 보호자 모드
- (2) 기기 목록 탭 삭제 (Play 스토어 정책 고려)

### 추가
- (1) 홈 공유기 등록: [등록] / [등록 확인], 같은 이름 묶기, 신호 막대, 저장 목록, **홈 PC 블루투스**(페어링) 귀가 판정
- (2) 현재 위치: 지도·복사·즉시 공유, 보호자 바로 걸기
- (3) 알림 설정: **귀가·외출·미귀가 알림**(보낼 곳 선택), **긴급 SOS**(보호자 전화 + 위치 전송, 홈 화면 바로가기)
- (4) 위치 보내기: 보내는 사람 별명, 본인 폰 알림, 일반 이메일·카톡 이메일(앱 비밀번호 자동 발송), 카톡 본인 메시지, 텔레그램(설정 도우미·초대 링크), 일반 문자, **외출 중에만 보내기**
- (5) 보호자 모드: **원격 위치 요청**(보호자가 텔레그램 봇에 "위치" → 자동 답장), 가족 전체 조회·비밀번호 잠금(개발 중)
- 위치 메시지: ■ 항목 구분, 지도 링크 3개(구글·카카오·네이버)
- 백그라운드 서비스: 재부팅·업데이트 후 자동 재시작, 절전 중 알람 전송
