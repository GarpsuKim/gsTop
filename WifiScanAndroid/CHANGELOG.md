## 1.5.0 (versionCode 6) — 2026-11-23

> ⚠ 설치 후 꼭: (1) 공유기 화면에서 집 공유기·집 PC 블루투스를 **◉ 홈** 으로 바꿔 주세요.
> 기존에 등록된 공유기·블루투스는 모두 **기타**로 시작하며, 기타는 귀가로 보지 않습니다.

### 추가
- **홈 / 기타 구분**: (1) 공유기 화면의 저장된 공유기·블루투스 기기마다 라디오 ◉ 홈 / ◉ 기타 (반드시 하나, 고르면 바로 저장·다시 판정)
  - **기타**(학교·회사·할머니댁·회사 PC·차 등)는 연결되거나 가까이 있어도 **귀가로 보지 않음** (외출로 처리, 귀가 알림 없음)
  - 메인 화면: 기타는 별명(없으면 "기타" / 기기 이름)만 **파란색**으로
  - 위치 메시지 첫 줄: `🚶 외출 (할머니댁) · 공유기 …`, `🚶 외출 (회사 PC) · 블루투스 …`
  - [등록 확인] 팝업: 이름 옆에 [홈] / [기타]
  - '홈'으로 체크된 공유기·블루투스가 하나도 없으면 "판정 불가" 안내 (외출 알림을 잘못 보내지 않음)
- **블루투스 기기 별명** 칸 (공유기 별명과 같음): 메인 상태, 위치 메시지 첫 줄 `🏠 홈 (거실 PC) · 블루투스 …`, [등록 확인], 상단 알림에 표시
- 메인 화면 상태 자리: 연결된 홈 공유기(또는 홈 블루투스 기기)에 별명이 있으면 '홈' 대신 **별명** (길면 글자 자동 축소)

### 바뀐 점
- 별명 칸이 비어 있으면 **진한 빨간 칸 + 흰 글씨 "별명을 입력하세요"**
- 탭 이름·번호: **(1) 공유기 · (2) 알림 설정 · (3) 위치 보내기 · (4) 응답 모드 · (5) 보호자 전용 모드** (화면 번호는 그대로)
- 1020: 공유기 줄과 위도 줄 사이를 넉넉히

### 추가

  - 첫 줄 **공유기: 이름, MAC, 등록 별명** (와이파이 연결이 없으면 "연결 안 됨")
  - 맨 끝 **지도 링크 7개**: 구글 · 네이버 · 카카오 · 티맵 · 아틀란 · 웨이즈 · 맵스미
    - 그 지도 앱이 깔려 있으면 앱으로 바로, 없으면 웹 지도 (웹 지도가 없는 티맵·아틀란·맵스미는 Play 스토어)
- **공유기 등록 별명**: (1) 저장된 공유기마다 '별명' 칸 (예: 우리집 거실, 입력하면 바로 저장)
  - 1020 공유기 줄, [등록 확인] 팝업, 위치 메시지 첫 줄 `🏠 홈 (우리집 거실) · 공유기 …` 에 표시
- **보호자 관계**: 나의 보호자(1100)·피보호자(1058) 카드에 [관계 ▼] (부모·조부모·배우자·선생님·친구 … 기타, 고르기 팝업 1102)
- 나의 보호자(1100) 카드에 **[테스트]**: 보호자에게 등록 안내 이메일 + 문자 앱. [삭제]는 확인(1101) 후 해제 안내 이메일 + 문자 앱

### 바뀐 점
- 메인 화면 2번째 줄: **[📍 현재 위치] · 상태 · [🆘 SOS]**
- 상태 표시를 한국말로: HomeBack → **홈**, NotHome → **외출** (메인 화면, 위치 메시지 첫 줄, 상단 알림, 안내 문구 모두)
- **위치 정확도 개선**: 구글 통합 위치(Fused) 사용, 오래되거나 부정확한 마지막 위치는 다시 쓰지 않음
- **네이버 지도 링크**: 지도 중심만 옮기던 형식 → 그 자리에 "현재 위치" 핀이 찍히는 형식
- (1) 화면 [보호자 등록] 버튼 → **[나의 보호자]**, 화면 제목 "나의 보호자 등록"

### 삭제

## 1.3.0 (versionCode 4) — 2026-11-22

### 추가
- **(6) 보호자 전용 모드** 탭(1058): 보호자가 피보호자를 관리
  - 피보호자 카드(이름·전화번호·이메일), [연락처에서 선택], [등록], [삭제](확인 1059), 좌우 넓은 [피보호자 추가]
  - [테스트]: 내 Gmail → 피보호자 이메일로 테스트 메일
  - [지금 위치 확인]: 내 Gmail → 피보호자 이메일로 제목 `#where` 메일 → 피보호자 폰이 위치를 내 Gmail 로 회신
- **물어보고 회신**: 자동 회신이 꺼져 있으면 "보호자 ○○님으로부터 위치 질문을 받았습니다. 회신할까요?" 알림 [Yes] [No], 알림을 누르면 같은 질문 팝업(1057)
- **앱 시작 때 받은편지함 확인**: 앱을 켤 때(및 다시 접속할 때) 받은편지함에 남아 있는 위치 요청 메일을 찾아 회신

### 바뀐 점
- (5) 보호자 모드 → **(5) 응답 모드**, 체크박스 "이메일 위치 요청에 자동으로 회신응답"
- 이메일 위치 요청 감시는 체크박스와 상관없이 **Gmail 인증 + 보호자 이메일**이 있으면 항상 동작 (체크박스는 자동 회신 / 물어보고 회신 선택)
- 요청 메일 제목을 **영어 `#where` 로 고정**, 대소문자는 아무렇게나 섞여도 됨: `#WHERE`, `#wHeRe`, `Re: #where`, `#where please`, 전각 `＃ｗｈｅｒｅ` (한글 `#위치` 는 더 이상 인식 안 함)
- 처리한 위치 요청 메일은 받은편지함에서 **삭제**(휴지통, 30일 뒤 완전 삭제). 등록 안 된 주소의 메일은 그대로 둠
- 탭이 6개가 되어 탭 글자를 조금 작게

## 1.2.0 (versionCode 3) — 2026-11-22

### 추가
- **이메일 원격 위치 요청** (권한·가입 필요 없음): 보호자가 사용자 Gmail 로 제목 "#위치" 메일을 보내면, 앱이 받은편지함을 지켜보다가(IMAP IDLE) 위치를 이메일로 자동 회신
  - (5) 보호자 모드 맨 위에 켜기/끄기, 감시 상태, [지금 확인] 진단 팝업(1055)
  - 제목은 너그럽게 판단: `#위치 알려줘`, `Re: #위치`, 전각 `＃`, 아이폰식 한글 등
  - 보호자 등록(1100)에 적힌 이메일에서 온 요청에만 회신, 사용자의 다른 메일은 읽음 표시도 바꾸지 않음
- **사용자 등록**(1075) 화면: 기본 정보(이름·별명은 모든 메시지의 보내는 사람), 발신 Gmail 인증(6자리 인증번호), 텔레그램, Tailscale·PC 서버, 긴급 의료 정보(SOS 에 첨부), 설정 백업·복원
  - 인증되면 [인증 메일 보내기] 비활성, 제목 줄 [변경]으로 인증 폐기·재인증(1077), 영역마다 굵은 구분선
- **보호자 등록**(1100)을 별도 화면으로: 보호자 카드(이름·전화번호·이메일) 추가·삭제, 연락처에서 선택
- **일반 문자(자동)**: 솔라피 API 로 폰에서 직접 문자 발송 (설정 1235, 알림·SOS 채널 포함)
- 모든 위치 메시지 첫 줄에 현재 상태 (🏠 HomeBack · 공유기/블루투스 이름 / 🚶 NotHome)
- 앱 시작·종료 때 현재 위치 통보
- 모든 화면·팝업 맨 아래에 화면 번호 (목록: SCREENS.md)

### 바뀐 점
- 발신 이메일은 **Gmail 만** 지원, 보내는 계정은 사용자 등록(1075) 한 곳에서만 입력
- (4) 위치 보내기: 맨 끝에 **공통 보내는 시각**(지정 시각/일정 간격) + [저장] — 본인 폰 알림·일반 이메일·카톡 본인 메시지·일반 문자가 함께 씀 (텔레그램은 자체 간격)
- (4) 각 설정 팝업에서 [저장]하면 그 줄이 자동으로 체크(켜짐)
- 일반 이메일(1150): 받는 사람만 입력 (최대 5명, 한 줄에 한 명)
- 카톡 본인 메시지도 지정 시각에 보낼 수 있음
- (1) 홈 공유기 등록: 저장된 공유기 / 홈 PC 블루투스 / 검색 결과 3개 영역 + 굵은 구분선, 영역마다 [저장], [재검색]

### 삭제
- 카톡 이메일(1160), 일반 이메일 수동 발송(Gmail 작성 화면)
- (4) '보내는 사람 별명' 줄(1130) → 사용자 등록의 이름 사용
- (2) 현재 위치의 보호자 전화 걸기 버튼 (SOS 는 오른쪽 위 버튼)
