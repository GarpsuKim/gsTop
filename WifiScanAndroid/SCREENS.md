# 화면 번호 목록

모든 화면 맨 아래 **검은 줄에 흰 글자**로 **"화면 ○○○○"** 이 표시됩니다.
수정 요청은 **"○○○○번 화면의 △△"** 처럼 말하면 됩니다.

## 번호 규칙
- 처음 부여: **1010 부터 10씩** 증가
- 이후 화면을 **추가·삽입**할 때는 그때마다 번호를 정해서 붙임 (빈 번호 사용, 예: 1095)
- 코드: `ScreenId.tag(...)` / 탭은 `ScreenId.label(...)`
