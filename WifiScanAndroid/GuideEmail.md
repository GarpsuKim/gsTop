# 집에왔어요 — 발신 이메일 등록 안내

앱이 **알림 없이 자동으로 위치 메일을 보내려면**, 보내는 데 쓸 **내 메일 계정**과
그 계정의 **앱 비밀번호**를 등록해야 합니다.

- 사용할 수 있는 메일: **구글(@gmail.com), 네이버(@naver.com), 카카오(@kakao.com)** 3가지
- **앱 비밀번호** = 다른 프로그램(이 앱)이 메일을 보낼 때 쓰는 **별도의 비밀번호**입니다.
  평소 로그인 비밀번호와 다르며, 언제든 삭제(폐기)할 수 있습니다.

> ⚠️ 앱 비밀번호는 내 메일함 전체에 접근할 수 있는 열쇠입니다. 다른 사람에게 알려 주지 마세요.

---

## 1. 구글 (Gmail)

1. **2단계 인증 켜기** — 꺼져 있으면 앱 비밀번호 메뉴가 나오지 않습니다.
   - https://myaccount.google.com/security → **2단계 인증** → 켜기
2. **앱 비밀번호 만들기**
   - https://myaccount.google.com/apppasswords
   - 앱 이름에 `집에왔어요` 입력 → **만들기**
   - 화면에 나온 **16자리**(예: `abcd efgh ijkl mnop`)를 복사
     (창을 닫으면 다시 볼 수 없으니 바로 복사하세요)
3. Gmail 은 SMTP 가 기본으로 켜져 있어 추가 설정이 없습니다.

## 2. 네이버

1. **2단계 인증 켜기**
   - https://nid.naver.com → 로그인 → **내정보** → **보안설정** → **2단계 인증**
2. **애플리케이션 비밀번호 만들기**
   - 같은 화면의 **애플리케이션 비밀번호 관리** → 종류 선택(기타/직접 입력) → **생성**
   - 나온 비밀번호를 복사
3. **메일 보내기(SMTP) 켜기** — 꼭 해야 합니다
   - https://mail.naver.com → **환경설정** → **POP3/IMAP 설정** → **POP3/SMTP 사용: 사용함** → 저장

## 3. 카카오 (카카오메일)

1. **카카오메일 주소 확인** — `아이디@kakao.com` 메일 주소가 있어야 합니다
   - https://mail.kakao.com (없으면 여기서 카카오메일 주소를 만듭니다)
2. **메일 보내기(SMTP) 켜기**
   - https://mail.kakao.com → **환경설정** → **IMAP/SMTP 사용** → 사용함
3. **2단계 인증 + 앱 비밀번호 만들기**
   - https://accounts.kakao.com → **계정 보안** → **2단계 인증** 켜기
   - 같은 곳의 **앱 비밀번호** → 생성 → 복사

> 메뉴 이름은 각 회사의 화면 개편에 따라 조금 다를 수 있습니다.

---

## 4. 앱에 등록하기

1. 앱 **(1) 홈 공유기 등록** 탭 → **[사용자 등록]** (화면 1075)
2. **■ 발신 이메일**
   - 보내는 이메일: 내 메일 주소 (예: `mygmail@gmail.com`)
   - 앱 비밀번호: 위에서 복사한 비밀번호 붙여넣기 (공백은 자동으로 지워짐)
3. **[인증 메일 보내기]** → 내 메일함에 온 **6자리 인증번호** 확인
4. 인증번호 입력 → **[확인]** → **✓ 검증됨** 이 나오면 끝

등록한 계정은 **일반 이메일(1150)**, **카톡 이메일(1160)** 자동 발송에 그대로 쓰입니다.

---

## 5. 안 될 때

| 나오는 메시지 | 해결 |
|---|---|
| 로그인 실패 - 이메일 주소/앱 비밀번호를 확인하세요 | 평소 비밀번호가 아니라 **앱 비밀번호**를 넣었는지, 2단계 인증이 켜져 있는지 확인. 앱 비밀번호를 새로 만들어 다시 입력 |
| 보내는 계정은 구글·네이버·카카오만 사용할 수 있습니다 | 3가지 중 하나의 메일 주소로 바꾸세요 |
| 연결 실패 (인터넷 확인) | 인터넷 연결 확인. 회사·학교 Wi-Fi 는 메일 포트(465)를 막는 경우가 있어 LTE/5G 로 시도 |
| 인증번호 메일이 안 와요 | 스팸함 확인, 네이버·카카오는 **SMTP 사용** 설정을 다시 확인 |

**앱 비밀번호를 더 이상 쓰지 않으려면**: 위 각 서비스의 앱 비밀번호 화면에서 해당 항목을 **삭제**하면 즉시 효력이 없어집니다.
