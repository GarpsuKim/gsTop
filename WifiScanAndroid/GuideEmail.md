# 집에왔어요 — 발신 이메일 등록 안내 (네이버 · 카카오 · 구글)

앱이 **알림 없이 자동으로 위치 메일을 보내고**, 보호자가 보낸 **위치 요청 메일(`#where`)에 자동 회신**하려면,
내 메일 계정 하나와 그 계정의 **(앱) 비밀번호**를 앱에 등록해야 합니다.

| 고를 수 있는 메일 | 보내는 서버 (SMTP) | 받는 서버 (IMAP) | 미리 할 일 |
|---|---|---|---|
| **@naver.com** (네이버) | `smtp.naver.com` SSL 465 | `imap.naver.com` SSL 993 | 메일 환경설정에서 **IMAP/SMTP 사용** 켜기 (+ 2단계 인증 사용 시 애플리케이션 비밀번호) |
| **@kakao.com** (카카오) | `smtp.kakao.com` SSL 465 | `imap.kakao.com` SSL 993 | 메일 환경설정에서 **IMAP/SMTP 사용** 켜기 (+ 2단계 인증 사용 시 앱 비밀번호) |
| **@gmail.com** (구글) | `smtp.gmail.com` SSL 465 | `imap.gmail.com` SSL 993 | **2단계 인증** 켜기 + **앱 비밀번호** 만들기 |

- 서버 주소는 앱이 알아서 고릅니다. 사용자는 **아이디, 메일 종류, 비밀번호**만 넣으면 됩니다.
- **받는 사람**(보호자)은 어떤 메일이든 괜찮습니다. 위 3가지 제한은 **보내는 내 계정**에만 해당합니다.
- **앱 비밀번호** = 다른 프로그램(이 앱)이 메일을 주고받을 때 쓰는 **별도의 비밀번호**입니다.
  평소 로그인 비밀번호와 다르며, 언제든 삭제(폐기)할 수 있습니다.

> ⚠️ 앱 비밀번호는 내 메일함 전체에 접근할 수 있는 열쇠입니다. 다른 사람에게 알려 주지 마세요.

## 1. 네이버 (@naver.com)

### 1-1. IMAP/SMTP 사용 켜기 (꼭 필요)

1. PC 또는 모바일 웹에서 네이버 메일 접속: https://mail.naver.com
2. 왼쪽 아래(또는 위) **환경설정** → **POP3/IMAP 설정**
3. **IMAP/SMTP 설정** 탭 → **IMAP/SMTP 사용: 사용함** → **저장**

### 1-2. 비밀번호 준비

- **2단계 인증을 쓰는 경우 (권장)** — **애플리케이션 비밀번호**를 만들어 사용합니다.
  1. https://nid.naver.com 접속 (네이버 로그인) → **내정보** → **보안설정**
  2. **2단계 인증** → **관리** → **애플리케이션 비밀번호 관리**
  3. 종류에서 **직접 입력** → 이름 `집에왔어요` → **생성하기**
  4. 화면에 나온 비밀번호를 복사 (창을 닫으면 다시 볼 수 없으니 바로 복사)
- **2단계 인증을 쓰지 않는 경우** — 네이버 **로그인 비밀번호**를 그대로 넣습니다.
  (보안을 위해 2단계 인증 + 애플리케이션 비밀번호를 권장합니다)

도움말: 네이버 고객센터 https://help.naver.com → "메일" → "POP3/IMAP", "애플리케이션 비밀번호" 검색

## 2. 카카오 (@kakao.com)

> 카카오메일 주소(**@kakao.com**)가 있어야 합니다. 카카오계정 이메일이 다른 메일(예: @daum.net, @gmail.com)이면
> 카카오메일(https://mail.kakao.com)에 들어가 **@kakao.com 주소를 먼저 만드세요**.
> (@daum.net · @hanmail.net 은 지원하지 않습니다)

### 2-1. IMAP/SMTP 사용 켜기 (꼭 필요)

1. 카카오메일 접속: https://mail.kakao.com
2. **환경설정** (톱니바퀴) → **IMAP/SMTP**
3. **IMAP/SMTP 사용: 사용함** → **저장**

### 2-2. 비밀번호 준비

- **2단계 인증을 쓰는 경우 (권장)** — **앱 비밀번호**를 만들어 사용합니다.
  1. https://accounts.kakao.com 접속 (카카오 로그인) → **계정 보안**
  2. **2단계 인증** 사용 → **앱 비밀번호** → 이름 `집에왔어요` → **생성**
  3. 나온 비밀번호를 바로 복사
- **2단계 인증을 쓰지 않는 경우** — 카카오계정 **로그인 비밀번호**를 넣습니다.

도움말: 카카오 고객센터 https://cs.kakao.com → "카카오메일" → "IMAP/SMTP", "앱 비밀번호" 검색

## 3. 구글 (@gmail.com)

### 3-1. 2단계 인증 켜기 (꼭 필요)

꺼져 있으면 앱 비밀번호 메뉴가 나오지 않습니다.

- https://myaccount.google.com/security → **2단계 인증** → 안내에 따라 켜기

### 3-2. 앱 비밀번호 만들기

1. https://myaccount.google.com/apppasswords 접속 (구글 로그인)
2. 앱 이름에 `집에왔어요` 입력 → **만들기**
3. 화면에 나온 **16자리**(예: `abcd efgh ijkl mnop`)를 복사 (공백은 앱이 자동으로 지움)

Gmail 은 SMTP/IMAP 이 기본으로 켜져 있어 추가 설정이 없습니다.

도움말: https://support.google.com/accounts/answer/185833 (앱 비밀번호로 로그인)

## 4. 앱에 등록하기

1. 앱 **(1) 공유기** 탭 → **[사용자 등록]** (화면 1075)
2. **■ 발신 이메일**
   - 아이디: `@` 앞부분만 입력 (예: `hong123`)
   - 오른쪽 **[@… ▼]** 를 눌러 메일 종류 고르기: `@naver.com` / `@kakao.com` / `@gmail.com`
     (고른 메일에 맞는 준비 안내가 비밀번호 칸 아래에 나옵니다)
   - 앱 비밀번호: 위에서 만든 비밀번호 붙여넣기
3. **[인증 메일 보내기]** → 내 메일 받은편지함에 온 **6자리 인증번호** 확인
4. 인증번호 입력 → **[확인]** → **✓ 검증됨** 이 나오면 끝

등록한 계정은 다음에 그대로 쓰입니다.

- **(3) 위치 보내기** — 일반 이메일 자동 발송
- **(4) 응답 모드** — 보호자의 위치 요청 메일(제목 `#where`) 감시와 자동 회신
- **[...] 메뉴 → [로그 보내기]** — 로그 파일 첨부 메일
- 보호자 등록 안내 메일, (5) 보호자 전용 모드의 [테스트]·[지금 위치 확인]

메일 종류나 아이디를 바꾸려면 **■ 발신 이메일** 제목 줄 오른쪽 **[변경]** → 다시 인증합니다.

## 5. 안 될 때

| 나오는 메시지 | 해결 |
|---|---|
| 로그인 실패 - 이메일 주소/앱 비밀번호를 확인하세요 | **네이버·카카오**: 메일 환경설정의 **IMAP/SMTP 사용**이 켜져 있는지, 2단계 인증을 쓰면 **앱(애플리케이션) 비밀번호**를 넣었는지 확인. **구글**: 2단계 인증을 켜고 만든 **앱 비밀번호(16자리)**인지 확인. 비밀번호를 새로 만들어 다시 입력 |
| 보내는 계정은 네이버·카카오·구글 … 만 사용할 수 있습니다 | 아이디 칸에 다른 메일 주소 전체를 넣지 말고, @ 앞만 넣은 뒤 [@… ▼] 에서 메일 종류를 고르세요 |
| 연결 실패 (인터넷 확인) | 인터넷 연결 확인. 회사·학교 Wi-Fi 는 메일 포트(465·993)를 막는 경우가 있어 LTE/5G 로 시도 |
| 서버 인증서 확인 실패 | 공용 Wi-Fi(로그인 화면이 있는 곳)에서 생김. LTE/5G 로 다시 시도 |
| 인증번호 메일이 안 와요 | 스팸함(네이버·카카오), 스팸함·프로모션함(Gmail) 확인 |
| (4) 응답 모드 [지금 확인]에서 로그인 실패 | 보내기는 되는데 받기만 안 되면 **IMAP** 사용이 꺼져 있는 경우가 많습니다 (네이버·카카오 환경설정) |

참고: 네이버·카카오는 새 메일 즉시 알림(IMAP IDLE)을 지원하지 않을 수 있습니다. 그런 경우 앱이 **1분마다** 받은편지함을 확인하므로, 위치 요청에 대한 회신이 최대 1분 정도 늦을 수 있습니다.

**비밀번호를 더 이상 쓰지 않으려면** 만든 곳에서 `집에왔어요` 항목을 **삭제**하면 즉시 효력이 없어집니다.

- 네이버: https://nid.naver.com → 보안설정 → 2단계 인증 → 애플리케이션 비밀번호 관리
- 카카오: https://accounts.kakao.com → 계정 보안 → 앱 비밀번호
- 구글: https://myaccount.google.com/apppasswords
