# 집에왔어요

집 공유기(Wi-Fi) 연결 여부로 **귀가(HomeBack) / 외출(NotHome)** 상태를 확인하고,
현재 위치를 **텔레그램 · 카카오톡 · 이메일**로 자동 전송하는 안드로이드 앱입니다.

> 어린이, 노약자, 치매 어르신들의 **안심 귀가 확인**에 유용합니다.
> PC 서버 없이 **폰 하나로 단독 사용**할 수 있습니다.

- 패키지: `com.garpsu.wifiscan`
- 지원: Android 6.0 (API 23) 이상 / 대상 API 34
- 언어: Java 17, AndroidX 미사용, 화면은 XML 없이 코드로 구성

---

## 주요 기능

### 화면 맨 위

| 위치 | 버튼 | 설명 |
|---|---|---|
| 왼쪽 | [초기화] | 모든 설정 삭제 → 처음 설치한 상태 (확인 후 실행, 되돌릴 수 없음) |
| 가운데 | ☐ 백그라운드 실행 | 앱을 닫아도 귀가 감지, 상단 고정 알림 표시 (아래 [백그라운드 동작](#백그라운드-동작) 참고) |
| 오른쪽 | [종료] | 앱 닫기 |

### 상단 상태 표시
- 지금 연결된 공유기가 등록한 **홈 공유기**면 초록색 **HomeBack**, 아니면 빨간색 **NotHome**
- 앱 실행 시 즉시 판정 후 10초마다 다시 확인
- 홈 공유기가 등록되지 않았으면 실행할 때 **안내 팝업** 표시

### (1) 홈 공유기 등록 탭
- 주변 Wi-Fi 스캔: 이름(SSID), MAC(BSSID), 신호 세기, 대역/채널, 보안 방식
- **같은 이름(SSID) 묶기**: 이름 줄을 체크하면 2.4GHz/5GHz 공유기를 한꺼번에 선택
- **신호 세기 막대** `▂▄▆█`와 색상(강: 초록 / 중: 주황 / 약: 빨강)
- **연결 중인 공유기** 강조(📶 연결됨) 및 맨 위 표시
- 모든 이름 앞에 `■` 표시
- **저장된 공유기 목록**: 주변에 안 보여도 표시, [삭제] 가능
- **홈 PC 블루투스**: 폰과 미리 페어링한 PC를 체크해 두면, PC가 가까이 있을 때도 HomeBack으로 판정
  - Wi-Fi가 꺼져 있거나 공유기가 바뀌어도 귀가 확인 가능 (공유기 또는 PC 중 하나만 확인되면 '집')
  - PC 쪽 프로그램 수정 없음. PC 블루투스만 켜져 있으면 됨
  - 공유기 밖일 때 약 3분마다 PC를 찾아봄 (찾으면 3분간 '집'으로 유지)
  - [블루투스 설정 (페어링)], [지금 확인] 버튼

### (2) 현재 위치 탭

- **🆘 SOS** (화면 오른쪽 위 [종료] 아래, 2초 길게 누르기): 첫 번째 보호자에게 전화 + 설정된 자동 채널(텔레그램, 자동 이메일)로 위치 즉시 전송
- 📞 **보호자 바로 걸기** 버튼 (최대 3명)
- "전화 걸기" 권한이 없으면 번호가 입력된 전화 화면까지만 띄움
- 112·119 자동 발신은 Android 정책상 불가

버튼 4개:

| 버튼 | 동작 |
|---|---|
| 검색시작 | GPS/네트워크로 위도·경도·정확도 확인, 주소·우편번호 조회 |
| 지도 | 설치된 지도 앱(구글·카카오·네이버 등)으로 열기 |
| 복사 | 위치 메시지를 클립보드에 복사 |
| 즉시 공유 | 카톡·문자 등으로 바로 공유 |

### (3) 알림 설정 탭

**■ 귀가 · 외출 순간 알림**
- ☐ 귀가하면 알림 (HomeBack): 2분 넘게 밖에 있다가 홈 공유기에 연결되는 순간
- ☐ 외출하면 알림 (NotHome): 집에 있다가 나가서 2분 넘게 돌아오지 않을 때
- 보낼 곳(여러 개 선택): 본인 폰 / 일반 이메일 / 카톡 이메일 / 카톡 본인 메시지 / 텔레그램 / 일반 문자
  - 받는 사람·계정·보내는 사람 별명은 (4) 위치 보내기 탭의 각 채널 설정을 그대로 사용
  - 자동 채널(텔레그램, 자동 이메일)은 바로 전송, 수동 채널은 알림을 눌러 직접 전송
- [테스트]로 지금 '귀가' 알림을 보내 볼 수 있음
- 위치 서비스가 꺼져 공유기를 확인할 수 없을 때는 상태를 바꾸지 않음 (잘못된 외출 알림 방지)

예시:
```
🏠 할머니 귀가했습니다 (HomeBack)  11-21 18:05
■ 공유기: MyHome

📍 할머니의 현재 위치 (11-21 18:05:12)
...
```

**■ 미귀가 알림**
- ☐ 미귀가 알림: [22:00] 까지 귀가하지 않으면 → '보낼 곳'으로 "⚠️ 아직 귀가하지 않았습니다" + 위치
- 외출 중임이 확실할 때만 보냄 (집인지 알 수 없으면 보내지 않음)

**■ 긴급 SOS**
- 보호자 전화번호 설정 (최대 3명, 첫 번째 = SOS 전화, 연락처에서 선택 가능)
- 홈 화면에 SOS 바로가기 추가 (누르면 3초 카운트다운, [취소] 가능). 앱 아이콘 길게 누르기 메뉴에도 SOS


### (4) 위치 보내기 탭

**■ 정해진 시각 위치 보내기** (각 줄 앞의 **☐ 체크박스 = 켜기/끄기**, 버튼 = 설정):

- ☐ **외출 중에만 보내기**: 집에 있으면 보내지 않음. 외출(2분 넘게 밖)이 확인되면 그때부터 보내고
  ('일정 간격'은 바로 1회, '지정 시각'은 다음 시각부터), 귀가하면 멈춤.
  홈 공유기/홈 PC 블루투스가 등록되어 있어야 하며, 집인지 알 수 없을 때는 안전하게 그냥 보냄

| 버튼 | 방식 | 설명 |
|---|---|---|
| 보내는 사람 별명 설정 | - | 받는 사람에게 표시할 별명 (예: 할머니) |
| 본인 폰 알림 | **자동** | 정해진 시각·간격마다 **이 폰에** 위치 알림 (보내지 않음). 알림에서 [지도 보기]·[공유] |
| 일반 이메일 | **자동** / 수동 | 앱 비밀번호로 자동 발송 / 알림 → Gmail 작성 화면 |
| 카톡 이메일 | **자동** / 수동 | 받는 사람의 카카오메일(@kakao.com)로 발송 → 카카오톡에서 받아봄. 설정은 일반 이메일과 별도 |
| 카톡 본인 메시지 | 수동 | 간격마다 알림 → 누르면 카톡 공유 화면 → 직접 [전송] |
| 텔레그램 | **자동** | 정해진 간격마다 봇으로 전송. 처음이면 **설정 도우미** 실행 |
| 일반 문자 | 수동 | 정해진 시각·간격마다 알림 → 누르면 받는 사람 번호·내용이 채워진 문자 앱 → 직접 [전송]. 문자 권한·가입 불필요, 지금 요금제로 발송. 짧게/전체 형식 선택, [연락처에서 선택] |

### (5) 보호자 모드 탭

**■ 원격 위치 요청 (텔레그램)**
- ☐ 원격 위치 요청 받기: 보호자가 텔레그램 봇에게 "위치" / "어디야" / `/where` 를 보내면
  이 폰이 "위치를 확인하고 있습니다..." → 현재 위치(주소·지도 링크)를 자동 답장
- 텔레그램 '받는 사람'으로 등록된 보호자만 요청 가능 (다른 사람은 거절 메시지)
- 백그라운드에서 봇 메시지를 계속 기다림 (설정 도우미가 열려 있는 동안은 잠시 쉼)
- 배터리 '제한 없음' 권장, 폰 전용 봇 권장 (PC와 같은 봇이면 메시지를 서로 가져감)

**■ 그 밖의 보호자 기능**: 준비 중

```

■ 주소: 대한민국 서울특별시 중구 세종대로 110

■ 우편번호: 04524

■ 위도, 경도: 37.566500, 126.978000
   (정확도 12 m)

■ 측정 시각: 14:30:01

■ 지도에서 보기
   구글: https://maps.google.com/?q=37.566500,126.978000

   카카오: https://map.kakao.com/link/map/현재%20위치,37.566500,126.978000

   네이버: https://map.naver.com/p?c=126.978000,37.566500,17,0,0,0,dh
```

- 네이버 링크는 좌표 중심으로 지도를 엽니다 (핀 표시 없음)

## 처음 설정하기

### 텔레그램 (완전 자동, 추천)
**(4) 위치 보내기 → [텔레그램 (자동)]** 을 누르면 설정 도우미가 열립니다.

| 단계 | 할 일 |
|---|---|
| 1. 봇 만들기 | [BotFather 열기] → `/newbot` → 봇 이름 → 봇 아이디(`…bot`으로 끝남) |
| 2. 토큰 넣기 | BotFather 메시지를 복사하고 돌아오면 **자동으로 붙여넣기·확인** |
| 3. 받는 사람 초대 | [받는 사람에게 링크 보내기] → 카톡·문자로 초대 링크 전송 |
| 4. 연결 확인 | 받는 사람이 링크를 누르고 [시작] → **앱이 자동 등록** (3초마다 확인) |
| 5. 테스트 | [테스트 보내기]로 받는 사람 폰에 도착하는지 확인 |
| 6. 시작 | 보내는 사람 이름, 간격 선택 → [시작하기] |

- 초대 링크에는 **초대 코드**가 들어 있어, 그 링크로 들어온 사람만 등록됩니다.
  링크가 퍼졌으면 [새 링크 만들기]로 예전 링크를 무효화하세요.
- PC 프로그램과 **봇을 따로** 쓰는 것을 권장합니다 (서로 메시지를 가져가지 않도록).
- 고급 사용자는 설정 팝업에서 직접 토큰·채팅 ID 입력, [받는 사람 찾기], [봇 링크 공유]도 가능합니다.

### 이메일 완전 자동 발송 (앱 비밀번호)
1. 구글 계정 **2단계 인증** 켜기
2. 앱 비밀번호 만들기: <https://myaccount.google.com/apppasswords>
3. [이메일 자동 송신] → **완전 자동 발송** 선택 → 보내는 이메일, 앱 비밀번호(16자리), 받는 사람 입력
4. 보내는 시각: **지정 시각(매일, 여러 개)** 또는 **일정 간격**
5. [지금 테스트]로 확인 후 [저장]

- 보내는 계정은 **구글·네이버·카카오만** 지원: Gmail(`smtp.gmail.com`), 네이버(`smtp.naver.com`), 카카오(`smtp.kakao.com`), 모두 SSL 465
- 네이버·카카오는 메일 환경설정에서 SMTP 사용을 켜야 합니다.
- 받는 사람의 **카카오메일(@kakao.com)** 로 보내면 카카오톡에서 바로 받아볼 수 있습니다 (카톡 자동 전송 대안).
  카톡 ID와 메일 주소는 다를 수 있으니 [카톡 메일 열기]로 실제 주소를 확인하세요.
- 서버 인증서를 확인한 뒤에만 로그인하므로 가짜 서버로 비밀번호가 새지 않습니다.

### 카카오톡 (반자동)
카카오톡은 다른 앱이 대신 전송하는 것을 허용하지 않아 **알림 → 누르면 카톡 공유 화면 → 직접 [전송]** 방식입니다.

## 백그라운드 동작
귀가 감지, 텔레그램, 카톡, 이메일 중 하나라도 켜져 있으면 **포그라운드 서비스**가 동작합니다.

- 상단에 **고정 알림 1개**: HomeBack/NotHome, 각 기능의 간격과 마지막 전송 결과(✓/✗)
- **귀가 알림**: 2분 이상 밖에 있다가 홈 공유기에 다시 연결되면 "HomeBack · 집에 도착했습니다"
- Wi-Fi 연결이 바뀔 때마다 검사 + 1분마다 재검사
- 화면이 꺼진 절전 상태에서도 알람으로 깨워 전송
- 재부팅 / 앱 업데이트 후 자동 재시작

### 꼭 확인할 폰 설정
- **위치(GPS) 서비스 켜기**: 꺼져 있으면 Android가 공유기 정보를 알려 주지 않아 감지 불가
- **배터리 → 제한 없음**: 설정 → 애플리케이션 → 집에왔어요 → 배터리 (삼성 등)
- **알림 허용** (Android 13 이상): 알림이 없으면 귀가 알림·카톡/Gmail 알림이 보이지 않음
- **알람 및 리마인더 허용** (Android 12 이상, 선택): 정해진 시각에 정확히 전송

## 빌드 / 설치 (PC)

| 파일 | 역할 |
|---|---|
| `setup.bat` | Android SDK 명령줄 도구 설치 (`C:\Android\sdk`), `local.properties` 생성 |
| `build.bat` | `gradlew assembleDebug` → `app\build\outputs\apk\debug\app-debug.apk` |
| `run_usb.bat` | USB 연결된 폰에 설치 후 실행 |
| `run_wifi.bat` | 무선 디버깅(IP:포트, 마지막 주소는 `adb_addr.txt`에 기억)으로 빌드·설치·실행 |
| `run_telegram.bat` | 빌드한 APK를 텔레그램 봇으로 내 폰에 전송 |
| `telegram_config.bat` | APK 전송용 `BOT_TOKEN`, `CHAT_ID` (**공유 금지**) |

처음 한 번:
```
setup.bat
build.bat
```

## 소스 구성

```
app/src/main/
├─ AndroidManifest.xml
└─ java/com/garpsu/wifiscan/
   ├─ MainActivity.java           화면(탭 3개), 각 설정 팝업
   ├─ HomeService.java            백그라운드: 귀가 감지, 텔레그램/카톡/이메일 예약 전송, 알림
   ├─ BootReceiver.java           재부팅·업데이트 후 서비스 재시작
   ├─ BtHome.java                 홈 PC 블루투스(페어링) 확인
   ├─ SosActivity.java            긴급 SOS (바로가기 카운트다운, 보호자 전화)
   ├─ TelegramSender.java         위치 메시지 생성(주소·지도 링크), 텔레그램 전송, 봇 정보/받는 사람 조회
   ├─ TelegramSetupActivity.java  텔레그램 설정 도우미 (단계별)
   └─ EmailSender.java            앱 비밀번호로 SMTP(SSL 465) 메일 발송
```

### 권한
| 권한 | 용도 |
|---|---|
| `ACCESS_FINE/COARSE_LOCATION` | Wi-Fi 스캔, 연결된 공유기(BSSID) 확인, 현재 위치 |

## 알려진 제한
- 카카오톡 완전 자동 전송 불가 (카카오 정책). 대안: 카카오 "나에게 보내기" API(본인에게만)
- 네이버 지도 링크는 핀 없이 좌표 중심으로 열림
- 텔레그램은 봇에게 온 메시지를 24시간만 보관 → 받는 사람 등록은 [시작] 직후에
- 위치 서비스가 꺼져 있으면 귀가 감지 불가
- 일부 제조사 폰은 배터리 절약으로 백그라운드 앱을 종료할 수 있음

## 검토 중
