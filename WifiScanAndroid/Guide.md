# 집에왔어요 — 사용 설명서

집 와이파이에 연결되면 **"집에 왔다"**, 끊기면 **"외출했다"**를 알아채서
가족(보호자)에게 알려 주는 앱입니다.
어르신, 어린이의 **안심 귀가 확인**에 쓰세요.

---

## 1. 처음 한 번만 하면 되는 설정

### ① 우리 집 와이파이 등록 — 가장 중요!
1. 집에서 앱을 엽니다.
2. **(1) 홈 공유기 등록** 탭 → **[검색시작]**
3. 목록에서 **우리 집 와이파이 이름**에 체크 ☑
4. **[등록]** → **[등록 확인]**으로 잘 들어갔는지 봅니다.

> 화면 위에 초록색 **HomeBack**이 보이면 성공입니다.

### ② 앱을 닫아도 동작하게
- 화면 맨 위 가운데 **☑ 백그라운드 실행**을 체크합니다.
- 휴대폰 **위치(GPS)** 를 켜 두세요. 꺼져 있으면 집인지 알 수 없습니다.
- 휴대폰 **설정 → 애플리케이션 → 집에왔어요 → 배터리 → "제한 없음"** 으로 바꿔 주세요.

### ③ 내 별명 정하기
- **(4) 위치 보내기** → **[보내는 사람 별명]** → 예: `할머니`
- 가족이 받는 메시지에 "📍 **할머니**의 현재 위치"처럼 나옵니다.

### ④ 보호자 전화번호 (SOS용)
- **(1) 홈 공유기 등록** → **[보호자 등록]**
- 예: `엄마 010-1234-5678, 아빠 010-9876-5432` (첫 번째 사람이 SOS 때 전화 받는 사람)

---

## 2. 가족에게 알리는 방법 고르기

**(4) 위치 보내기** 탭에서 쓰고 싶은 것만 고르세요. (줄 앞 ☐ = 켜기/끄기, 글자 버튼 = 설정)

| 방법 | 자동? | 이럴 때 추천 |
|---|---|---|
| **텔레그램** | 자동 | 가장 편함. 처음 누르면 **설정 도우미**가 차근차근 안내 |
| **일반 이메일** | 자동/수동 | 이메일로 받고 싶을 때 |
| **일반 문자** | 수동 | 알림을 누르면 문자 창이 열림 → [전송] |
| **카톡 본인 메시지** | 수동 | 알림을 누르면 카톡 창이 열림 → 받을 사람 골라 [전송] |
| **본인 폰 알림** | 자동 | 이 폰에만 위치 알림 (보내지 않음) |

> **자동** = 알아서 보냄 / **수동** = 알림을 눌러 직접 [전송]
> 각 설정 화면의 **[지금 테스트]**로 미리 한 번 보내 보세요.

---

## 3. 귀가·외출 알림 켜기

**(3) 알림 설정** 탭

- ☑ **귀가하면 알림** — 집에 도착하면 "🏠 할머니 귀가했습니다"
- ☑ **외출하면 알림** — 집을 나서서 2분이 지나면 "🚶 외출했습니다"
- ☑ **미귀가 알림 [22:00]** — 그 시각까지 안 들어오면 "⚠️ 아직 귀가하지 않았습니다"
- **보낼 곳**에서 위 2번에서 설정한 방법을 체크
- **[테스트]** 로 확인

---

## 4. 위급할 때 — SOS 🆘

- 화면 **오른쪽 위 빨간 [SOS]** 버튼을 **2초 동안 꾹** 누릅니다.
  → 첫 번째 보호자에게 **전화**가 걸리고, 가족에게 **현재 위치**가 갑니다.
- 손을 일찍 떼면 취소됩니다. (실수 방지)
- **(3) 알림 설정 → [홈 화면에 SOS 바로가기 추가]** 를 해 두면 앱을 열지 않고도 됩니다. (3초 뒤 작동, 그 사이 [취소] 가능)

> ※ 112·119는 앱이 자동으로 걸 수 없습니다. 삼성 폰은 **설정 → 안전 및 긴급 → 긴급 SOS**(측면 버튼 5번)도 함께 켜 두세요.

---

## 5. 보호자가 "지금 어디야?" 물어보기

- (텔레그램을 설정한 경우) **(5) 보호자 모드** → ☑ **원격 위치 요청 받기**
- 보호자가 텔레그램 봇에게 **"위치"** 라고 보내면, 이 폰이 **알아서** 현재 위치를 답장합니다.
- 등록된 보호자만 요청할 수 있습니다.

---

## 6. 자주 묻는 질문

**Q. 집에 있는데 NotHome으로 나와요.**
→ 위치(GPS)가 켜져 있는지, 와이파이에 연결되어 있는지 보세요. 집 와이파이가 바뀌었다면 다시 **[등록]** 하세요.

**Q. 앱을 닫으면 알림이 안 와요.**
→ **☑ 백그라운드 실행** 체크, 배터리 **"제한 없음"** 을 확인하세요.

**Q. 알림이 몇 분 늦게 와요.**
→ 화면이 꺼진 절전 상태에서는 늦어질 수 있습니다. 설정 → 앱 → 집에왔어요 → **알람 및 리마인더 → 허용**을 켜 주세요.

**Q. 처음부터 다시 하고 싶어요.**
→ 화면 왼쪽 위 **[초기화]** (모든 설정이 지워집니다)

**Q. 어떤 버전인지 궁금해요.**
→ **(5) 보호자 모드** 탭 맨 아래에 버전이 나옵니다.
